|---|---|

| `design.md` | The design specification. Component models, copy deck, motion, and accessibility checklist. |
| `task.md` | The build breakdown. Atomic tasks, dependencies, and sequence. |

All reviews, closing notes, and remediation records live in this folder alongside the primary specifications.
